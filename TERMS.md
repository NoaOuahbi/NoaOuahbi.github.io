# Site notes

This site is a family-managed project for Noa. It is not a child account,
public contact channel, or place to publish private details. The family
maintains the content and decides what, if anything, is shared.

## Public pages

The public website is static. Do not add exact age, school, location,
routines, contact details, or personal account information. Use only
guardian-approved media and content.

## Optional family area

The family sign-in feature is disabled until a separately hosted API and
GitHub OAuth app are configured. The API must restrict access to
guardian-approved adult accounts using `ALLOWED_GITHUB_LOGINS`. GitHub
credentials and database secrets must never be added to the frontend or Git.

## Music and browser storage

The shared playlist is empty by default. Family members should publish only
audio they have permission to share. Visitor-selected files and playback
preferences are kept in that visitor's browser and are not uploaded by the
music player.
